# leicafujicam

**leicafujicam** — ứng dụng máy ảnh chuyên nghiệp cho Android, được phát triển bởi **Hoàng & Muse**.

Ứng dụng mang tới trải nghiệm chụp ảnh nâng cao: chụp RAW/DNG, HDR hợp nhất nhiều khung hình, LUT màu điện ảnh, khung viền (frame) tùy biến, chế độ chụp đêm và nhiều công cụ xử lý ảnh tính toán khác — tất cả chạy trực tiếp trên thiết bị.

## Tính năng chính

- Chụp ảnh RAW (DNG) và JPEG/HEIC chất lượng cao
- HDR, Night Sight, hợp nhất nhiều khung hình giảm nhiễu
- Thư viện LUT màu, trình tạo LUT, khung ảnh (frame) tùy biến
- Chỉnh tay đầy đủ: ISO, tốc độ màn trập, lấy nét, cân bằng trắng
- Thư viện ảnh tích hợp, chỉnh sửa và xuất ảnh/video

## Thông tin bản dựng

- Package: `vn.hoang.leicafujicam`
- Phiên bản: 1.0.0
- Yêu cầu: Android 11 (API 30) trở lên, thiết bị arm64
